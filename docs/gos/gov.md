# Government

Правительство штата - Высший исполнительный орган, осуществляющий контроль над всеми государственными структурами и органами. Занимается непосредственной разработкой и внесением изменений в законодательную базу штата, заказом и сопровождением поставок медикаментов и материалов, а также контролем за налогообложением граждан.

## Функционал

| **Функция** | **Описание** |
|:-------------|:-------------|
| **Пригласить** | Пригласить человека вступить во фракцию |
| **Премировать** | Выдать премию сотруднику фракции |
| **Документы** | Показать человеку свои документы. Содержат Ваш никнейм и должность |
| **Лицензии** | Выдача лицензий на адвокатскую деятельность, рыбную ловлю, оружие, либо бизнес |
| **Наручники** | Надевает на человека наручники и обездвиживает его. Можно использовать на кнопку **X**, избегая меню **G** |
| **Конвой** | Заставляет человека следовать за Вами. Применимо только к игроку, на которого уже надеты наручники. Позволяет, подойдя к машине, посадить в неё человека (нажав по машине **G**). Можно использовать на кнопку **Z**, избегая меню **G** |
| **Обыск** | Обыскать человека на предмет нелегального оружия, а также просмотреть служебное удостоверение (при наличии). Применимо только к игроку, на которого уже надеты наручники |

## Выдача лицензий

Выдача производится через меню взаимодействия(см.выше) при наличии соответствующего права установленного лидером.
Функционально все 100% за выручку при продаже лицензии будут зачислены на счёт фракции. 

| **Лицензия** | **Стоимость** | **Назначение** |
|:--------------|:--------------:|:----------------|
| **На оружие** | 10.000$ | Для покупки оружия в AmmuNation и его дальнейшего легального ношения. |
| **На бизнес** | 50.000$ | Для возможности покупки бизнеса. |
| **Адвокатская деятельность** | 30.000$ | Для возможности ведения адвокатской деятельности. |
| **На рыбалку** | 10.000$ | Для возможности легально ловить рыбу, используя водные т/с. |
| **На охоту** | 10.000$ | Для возможности сдавать шкуру убитых животных скупщику. Без лицензии сдать шкуру самостоятельно невозможно. |

## Лишение лицензии на адвокатство

Лишение лицензии производится через меню взаимодействия(см.выше) при наличии соответствующего права установленного лидером.
Для этого необходимо подойти к метке рабочего компьютера на первом этаже, ввести никнейм человека и нажать на "Аннулировать лицензию". 

## Прокурор

Право выдаваемое лидером. Позволяет сотрудникам выпускать заключенных из тюрьмы, а также удалять информацию из базы данных о правонарушениях сделанных ранее. 

## Заказ поставок и выплата премий

В кабинете губернатора на метке рабочего компьютера у сотрудника при наличии соответствующих прав установленных лидером есть возможность заказа материалов, медикаментов, а также выплаты премий для государственных фракций. Сумма переводимая за премии списывается напрямую со счета фракции правительства.
