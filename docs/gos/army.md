## Функционал

| **Функция** | **Описание** |
|:-------------|:-------------|
| **Пригласить** | Пригласить человека вступить во фракцию |
| **Премировать** | Выдать премию сотруднику фракции |
| **Документы** | Показать человеку свои документы. Содержат Ваш никнейм и должность |
| **Военный билет** | Выдача военного билета игроку |
| **Наручники** | Надевает на человека наручники и обездвиживает его. Можно использовать на кнопку **X**, избегая меню **G** |
| **Конвой** | Заставляет человека следовать за Вами. Применимо только к игроку, на которого уже надеты наручники. Позволяет, подойдя к машине, посадить в неё человека (нажав по машине **G**). Можно использовать на кнопку **Z**, избегая меню **G** |
| **Обыск** | Обыскать человека на предмет нелегального оружия, а также просмотреть служебное удостоверение (при наличии). Применимо только к игроку, на которого уже надеты наручники |
| **Стяжки** | Снять стяжки с игрока |

## Тир

Для всех участников фракции существует бесплатный тир, в котором можно поднять уровень навыка "Стрельба".
Тренировка является бесплатной и имеет задержку между подходами в 60 минут.
